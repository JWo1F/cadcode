Code-first CAD

Write a model in JavaScript, see it live in the browser while you edit, and export STL for printing and PNG for previews. There is no modeling UI: your editor is the CAD system.

Open the playground GitHub 
npm install cadcode

A model is a module

Its default export is the model. The API keeps OpenSCAD's ideas — cube, cylinder, hull, difference, $fn — so OpenSCAD models port line by line. 

npx cadcode dev plate.js

The dev viewer rebuilds the model on every save and swaps it into the page without touching the camera. 

import { cube, cylinder, difference } from 'cadcode';

export default difference(
  cube([20, 20, 5], { center: true }),
  cylinder({ d: 6, h: 10, center: true }),
);

Watertight, always

Geometry runs on manifold, the boolean engine recent OpenSCAD uses. Every solid comes out printable.

Parameters and parts

Declare params and override them with --set. Export an object of named parts — an assembly, a box, a lid — and pick one per export.

STL and PNG

cadcode stl writes binary STL for the slicer. cadcode png renders previews, including a four-view sheet, without a browser.

Just JavaScript

Loops, functions, helper files, npm packages and TypeScript all work, because a program is an ordinary module.
